# myinitboard

Wi-Fi版 **iPad mini 6**（8.3インチ、論理解像度 744 × 1133 pt）の縦画面・横画面どちらでも快適に閲覧できる、Flutter製のパーソナルダッシュボードアプリです。

Slate系のダークテーマを採用し、広告なしで必要な情報（登録した各地点の現在天気、時間帯サマリー、時間ごとの推移、週間予報）を一画面で高密度かつ視覚的に把握できます。

---

## 🌟 主な機能と特徴

- **複数地点のスマートタブ ＆ 画面スワイプ切替（iPad最適化）**:
  - 設定から何地点でも自由に追加・削除可能（自宅、実家、職場、旅行先など）
  - **画面左右スワイプ対応**: iOS標準アプリのように、画面全体を左右にスワイプするだけで前後の地点へ直感的にページ送り切替が可能（`PageView` ＆ `BouncingScrollPhysics`）
  - **タブバー連動**: スワイプと上部タブバーの選択状態が双方向に完全連動。タブタップ時はスムーズなアニメーション遷移
  - 横スクロール可能なタブバー内に「今日の天気アイコン」「表示名」「現在の気温ピル」を表示し、タブを見るだけで全登録地点の最新天況が常に一目で把握可能
  - 選択した地点の天気カードが画面中央に美しい最大幅（`maxWidth: 860`）でゆったりと配置され、情報過多にならず抜群の視認性を実現
- **柔軟な地点カスタマイズ（表示名 ＆ 場所データの分離）**:
  - **表示名**: 「自宅」「職場」「おばあちゃんの家」など任意のカスタム名を自由に設定可能
  - **場所データ**: 地名入力でリアルタイム検索・候補サジェストからワンタップで正確な座標（緯度・経度）を自動補完
- **今日・明日の時間帯別サマリー**:
  - 午前（6-12時）/ 午後（12-18時）/ 夜（18-24時）の天気・最大降水確率・予想気温
  - **降水確率50%以上の視覚的強調**: 背景の水色ハイライト（`#330284C7`）と水色発光ボーダー（`#38BDF8`）で一目で警戒可能
- **時間ごとの詳細予報 & 週間予報のタブ切替**:
  - 各地点カード内のトグルスイッチ（`[ 1時間毎 ] [ 1日毎 ]`）でスムーズに切替（`AnimatedSwitcher`）
  - **表示状態の完全保持・永続化**: 場所タブ（東京 ↔ 大阪 ↔ 2地点比較）を切り替えても、直前に選択していた「1時間毎」または「1日毎」の表示モードが維持されます。さらに `SharedPreferences` にも保存されるため、次回起動時や再読み込み時にも前回の表示状態が自動復元されます。
  - **1時間毎**: 現在時刻から明日24:00までの1時間ごと予報（横スクロール、0:00日付境界ハイライト）
  - **1日毎**: 7日間の日別予報（曜日カラー識別、最高/最低気温、最大降水確率）
  - 表示を切り替えることで、iPad mini 6の横画面（高さ744pt）でもカードの縦幅をコンパクトに抑え、スクロールなしの1画面表示を実現
- **完全オフライン対応**:
  - 取得したJSONデータおよび取得日時を `shared_preferences` にローカルキャッシュ
  - Wi-Fi未接続時や通信エラー時でもエラー画面にならず、保存済みキャッシュから自動復元
  - ヘッダーにステータスバッジ（例: `取得: 11/14 18:30` / `⚠️ オフライン表示中 (取得: 11/14 08:00)`）を表示
- **プライバシー保護設計**:
  - 公開リポジトリに個人の住所や座標が流出しない安全な設定ロード機構

## 📱 iPad mini 6 最適化レスポンシブ設計

対象デバイスである iPad mini 6 の論理サイズ（縦: 744 × 1133 pt / 横: 1133 × 744 pt）に合わせて、`LayoutBuilder` によるブレークポイント（**850pt**）で画面構成を最適化しています。

| 画面向き | 画面幅 | レイアウト仕様 |
| :--- | :--- | :--- |
| **横画面** | **850pt 以上**<br>*(1133 × 744 pt)* | **左右2カラム・ワイドダッシュボード（横余白の解消）**<br>・最大幅1100ptまでフル活用し、横の無駄な余白を完全に排除<br>・**左カラム**: 現在の天気バナー ＋ 時間帯別サマリー<br>・**右カラム**: 1時間ごとの推移 ＋ 7日間の週間予報<br>・縦スクロール不要で、全情報が1画面に美しく収まるレイアウト |
| **縦画面** | **850pt 未満**<br>*(744 × 1133 pt)* | **全情報フルスタック表示（縦余白の解消）**<br>・高さ1133ptの縦長スペースを余すことなく贅沢に活用<br>・上から「現在天気」→「今日明日のサマリー」→「1時間予報」→「7日間の週間予報」をシームレスに一覧表示<br>・トグル（`[ すべて ] [ 1時間毎 ] [ 1日毎 ]`）で必要に応じて絞り込み表示も可能 |

## 🔒 プライバシー & 地点設定の仕様

GitHubのPublicリポジトリで安全に管理できるよう、コード内に個人的な地名や座標は一切ハードコーディングしていません。

### 地点設定のロード優先順位

```
1. SharedPreferences に保存されたユーザー設定値（最優先）
   ↓（未保存の場合）
2. assets/local_config.json の設定値（存在する場合のみロード、.gitignore対象）
   ↓（ファイルが無い場合）
3. アプリ内デフォルトフォールバック値（左: 東京 35.6895 / 139.6917、右: 大阪 34.6937 / 135.5023）
```

### 設定方法
1. **アプリ内UI（推奨・地名オートコンプリート対応）**:
   - ヘッダー右上の歯車アイコン（⚙️）をタップ
   - **地名からの自動検索・座標補完**: 場所名入力欄に「横浜市」「渋谷」「札幌」など任意の地名を入力すると、Open-Meteo Geocoding API により候補リストが即座に表示されます。候補をタップするだけで、**表示名・緯度・経度がワンタップで自動補完**されます。もちろん緯度・経度の手動微調整も可能です。
   - **タブ表示名の自動フォールバック**: タブ表示名を空欄のまま保存した場合でも、自動的に場所検索に入力されている地名がタブ表示名として適用されます。入力欄には一括消去用の✕クリアボタンも備えています。
   - 「保存して再取得」を押すと設定値が端末のローカルストレージ（`shared_preferences`）に保存され、即座に新しい地点の天気が取得・反映されます。
   - 「初期値に戻す」ボタンでいつでも初期デフォルト（東京・大阪）にリセット可能。
2. **ローカル設定ファイル（開発・初期プリセット用）**:
   - `assets/local_config.example.json` をコピーして `assets/local_config.json` を作成
   - 任意の地名・緯度・経度を記述（※このファイルは `.gitignore` によりコミット対象外です）

## 🏗️ アーキテクチャと拡張性

将来的に天気以外のダッシュボード機能（タスク管理、ローカルニュース、システムモニター等）を追加できるよう、Feature-Firstのモジュール設計を採用しています。

```
myinitboard/
├── .github/workflows/
│   └── build-ipa.yml                  # GitHub Actions (macOS) によるIPA自動ビルド
├── assets/
│   ├── local_config.example.json      # リポジトリ用サンプル設定ファイル
│   └── local_config.json              # ユーザー個別設定（.gitignore対象）
├── lib/
│   ├── main.dart                      # アプリ起動・将来の機能拡張土台（MainShellScreen）
│   ├── core/
│   │   ├── config_service.dart        # 地点設定管理（Prefs > local_config.json > Default）
│   │   └── theme.dart                 # Slate系ダークテーマ定義（Slate 900/800/700等）
│   └── features/
│       └── weather/
│           ├── models/                # 天気・地点データモデル、WMOコードマッピング
│           ├── services/              # Open-Meteo API通信 & SharedPreferencesキャッシュ
│           └── views/
│               ├── weather_dashboard_screen.dart # メイン画面（LayoutBuilder・ヘッダー）
│               └── widgets/           # 各種カード、バナー、グリッド、設定モーダル
```

## 🚀 開発・動作確認

### 前提環境
- Flutter SDK 3.50.0 以上
- Google Chrome（Webターゲット）

### ローカルWebの起動と停止

#### 1. 通常起動（Flutter 開発サーバー）
```bash
# 依存関係取得
flutter pub get

# Chromeで起動
flutter run -d chrome
```
- **停止方法**: 実行中のターミナルで `q` キーを押すか、`Ctrl + C` を入力します。

#### 2. 静的Webビルド配信（軽量HTTPサーバー）
```bash
# Web版のビルド
flutter build web

# ポート8080で配信
python -m http.server 8080 --directory build/web
```
- **停止方法**:
  - **フォアグラウンド実行時**: ターミナルで `Ctrl + C` を入力。
  - **バックグラウンド実行・プロセスが残った場合**: PowerShellで以下を実行して強制終了。
    ```powershell
    # python サーバーの停止
    Stop-Process -Name "python" -Force -ErrorAction SilentlyContinue

    # または flutter / dart プロセスの停止
    Stop-Process -Name "dart" -Force -ErrorAction SilentlyContinue
    ```
  - **AIエージェントが起動した場合**: チャットで「ローカルWeb止めて」と指示すれば、エージェント側で直ちにプロセスを安全に終了・解放します。

### テスト実行
ユニットテストおよびiPad mini 6の縦横レスポンシブテストを実行します。
```bash
flutter test
```

## 📦 iOSビルド（GitHub Actions）

本リポジトリには、GitHub Actions用のワークフロー [`.github/workflows/build-ipa.yml`](.github/workflows/build-ipa.yml) が組み込まれています。

- **トリガー**: `main` ブランチへのプッシュ、または手動実行（`workflow_dispatch`）
- **環境**: `macos-latest`
- **ビルド手順**:
  1. Flutter環境セットアップ
  2. `flutter build ios --release --no-codesign`
  3. 生成された `Runner.app` を `Payload/` に配置してzip圧縮（`myinitboard.ipa`）
  4. GitHub Actionsのアーティファクト（`myinitboard-ipa`）としてアップロード（保持期間14日）
- 生成された `.ipa` は、TrollStoreやAltStore、Sideloadly等のサイドロードツールを用いてiPad mini 6にインストール可能です。
